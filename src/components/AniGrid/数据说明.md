# WORD变量数据说明

| 序号 | 功能 | 数据类型 | PLC变量名称 |
| --- | --- | --- | --- |
| 1 | 动作进程 | WORD | DataW[0] |
| 2 | 前起落架到位信号 | WORD | DataW[1] |
| 3 | 左起落架到位信号 | WORD | DataW[2] |
| 4 | 右起落架到位信号 | WORD | DataW[3] |

## DataW[0]

| 位 | 含义 |
| --- | --- |
| 0 | 舱门开启动作中 |
| 1 | 舱门关闭动作中 |
| 2 | 起落架升起动作中 |
| 3 | 起落架落下动作中 |

## DataW[1]

| 位 | 含义 |
| --- | --- |
| 0 | 前舱门开启到位 |
| 1 | 前舱门关闭到位 |
| 2 | 前舱门锁定到位 |
| 8 | 前起落架升起到位 |
| 9 | 前起落架落下到位 |

## DataW[2]

| 位 | 含义 |
| --- | --- |
| 0 | 左舱门1开启到位 |
| 1 | 左舱门1关闭到位 |
| 2 | 左舱门1锁定到位 |
| 3 | 左舱门2开启到位 |
| 4 | 左舱门2关闭到位 |
| 5 | 左舱门2锁定到位 |
| 8 | 左起落架升起到位 |
| 9 | 左起落架落下到位 |

## DataW[3]

| 位 | 含义 |
| --- | --- |
| 0 | 右舱门1开启到位 |
| 1 | 右舱门1关闭到位 |
| 2 | 右舱门1锁定到位 |
| 3 | 右舱门2开启到位 |
| 4 | 右舱门2关闭到位 |
| 5 | 右舱门2锁定到位 |
